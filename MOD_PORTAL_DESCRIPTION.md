# Powered Concrete

Powered Concrete adds powered versions of concrete, refined concrete, and hazard concrete so your factory floor can carry electric coverage without visible power poles everywhere.

This Factorio 2.0 rebuild keeps exact tile-by-tile behaviour, so power only exists where powered concrete has actually been placed. It also removes the old `flib` dependency and includes cleaner runtime syncing, rebuild support, and Q / pipette support for all powered concrete variants.

## Features

- Powered Concrete
- Powered Refined Concrete
- Powered Hazard Concrete
- Powered Refined Hazard Concrete
- Hidden floor-based electric coverage
- Exact tile-by-tile powered floor logic
- Q / pipette support for normal, refined, and hazard variants
- `/powered-concrete-rebuild` admin command
- Factorio 2.0 compatible
