# ⚡ Powered Concrete

**Powered Concrete** adds powered versions of concrete, refined concrete, and hazard concrete so your factory floor can carry electric coverage without visible power poles everywhere.

Build cleaner. Expand faster. Keep your factory floor looking sharp.

---

## 🔌 What It Does

Powered Concrete turns your floor into a hidden power network.

Instead of placing power poles all over your factory, you can use powered concrete tiles to carry electric coverage directly through the ground. Power only exists where powered concrete has actually been placed, so it still feels like a proper tile-based system rather than a giant invisible power field.

This Factorio 2.0 rebuild keeps the behaviour **exact tile-by-tile**, removes the old `flib` dependency, includes cleaner runtime syncing, and keeps Q / pipette support for every powered concrete variant.

- ⚠️ **Refined Hazard Concrete**
- ⚡ **Powered Concrete**
- ⚡ **Powered Hazard Concrete**
- ⚡ **Powered Refined Concrete**
- ⚡ **Powered Refined Hazard Concrete**

Extra conversion recipes such as **Remove Powered Concrete Hazard Markings** and similar add/remove marking recipes are hidden so the inventory stays clean.

## 🛠️ Rebuild Command

If the hidden powered floor system ever gets out of sync, you can rebuild it with:

```text
/powered-concrete-rebuild
```

This is mainly useful after heavy mod changes, scripted tile edits, or save migration testing.
