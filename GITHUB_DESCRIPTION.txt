Powered Concrete adds powered versions of concrete, refined concrete, and hazard concrete for Factorio 2.0, letting factory floors carry electric coverage without visible power poles. Includes exact tile-by-tile hidden power by default, optional connector-grid UPS tuning, refreshed overlay icons, Q/pipette support, a clean visible floor recipe list, hidden conversion recipes, and migration support from PoweredConcreteSpaceAge 0.1.x saves.
